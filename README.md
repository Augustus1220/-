# 🚀 湖南科技大学嵌入式刷题

期末复习《嵌入式系统》背题背到头秃？来试试这个纯前端的极速刷题网页吧！
不需要装任何软件，没有后端，完全本地运行，点开即用。丝滑流畅，拯救你的期末考试~ 💯

## 📁 仓库里都有啥？

* **`index.html`**：刷题神器的网页本体。双击直接在浏览器打开，或者通过 GitHub Pages 在线访问！
* **`题库.txt`**：配套的纯文本题库文件（包含 300+ 道选择题）。打开网页后导入它就能生成电子考卷。
* **`嵌入式系统完整题库.docx`**：最原始的 Word 版题库，留作备份，方便大家自己打印或者复习使用。

## 🎮 怎么玩？

1. 直接访问本仓库的 GitHub Pages 链接（或者下载 `index.html` 用浏览器打开）。
2. 点击页面里的“选择本地文件”按钮，把仓库里的 `题库.txt` 喂给它。
3. 开启疯狂刷题模式！点选项秒出对错，底部还能一键呼出“全局答题卡”自由跳转。

祝大家逢考必过，全员满绩！🎉
