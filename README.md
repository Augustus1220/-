# 🚀 湖南科技大学嵌入式刷题

Gemini 随便跑了个刷题玩具 🤖
期末复习《嵌入式系统》背题背到头秃？来试试这个纯前端的极速刷题网页吧！
不需要装任何软件，没有后端，数据完全本地运行，安全且丝滑，点开即用。

## 📁 仓库里都有啥？

* **`index.html`**：刷题神器的网页本体。双击直接在电脑/手机浏览器打开，或者通过 GitHub Pages 在线访问！
* **`题库.txt`**：配套的纯文本题库文件（包含 300+ 道选择题）。打开网页后导入它就能生成电子考卷。
* **`嵌入式系统完整题库.docx`**：最原始的 Word 版题库，留作备份，方便大家自己打印或者复习使用。


1. 直接访问本仓库的 GitHub Pages 链接（或者下载 `index.html` 用浏览器打开）。
2. **第一步**：点击页面里的“📂 加载原题库”按钮，把仓库里的 `题库.txt` 喂给它。
3. **第二步**：点击“🚀 直接开刷全卷”，开启疯狂刷题模式！点选项秒出对错，底部还能一键呼出“答题卡”自由跳转。

* **🎯 专属错题本**：遇到错题不想重新刷全卷？在刷题界面右上角随时点击 `[📉 错题]`，将当前错题导出为 `.json` 文件。下次打开网页，在第二步选择“导入错题本”，系统会为你生成一张纯错题试卷，精准打击！
* **⏳ 进度存/读档**：刷了几百道题想去吃个饭，怕网页刷新记录全没？点击右上角 `[💾 存档]` 导出进度包。下次打开网页，先加载原 `题库.txt`，再点击“⏳ 恢复进度”导入你的存档包，瞬间回到你离开时的页面，之前的对错记录和正确率完美保留！
